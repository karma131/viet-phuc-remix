# Product-style garment catalog

The library and garment details display 19 independent AI-generated product illustrations. The traditional áo dài was regenerated in the same portrait 2:3 format, warm gray backdrop and studio lighting as the other images. The original user reference is preserved locally. Studio, try-on and outfit-result SVG layers remain interactive and independent of these catalog assets.

Images were created using the built-in `image_gen` tool, not the website's API key. They are static project assets, so `OPENAI_IMAGE_MODEL` can stay empty. Full prompts are recorded in [catalog-image-prompts.json](catalog-image-prompts.json). The áo ngũ thân illustration was revised to show exactly five visible buttons. The Nhật Bình image now follows the user's supplied red embroidered reference, with a rectangular collar panel, wide sleeves, five-color cuffs and patterned lower panels. This illustrates that specific reference rather than certifying historical rank or an authenticated original artifact.

Final browser assets are saved in `public/garments/` as 400px and 800px WebP variants. Original PNG copies are preserved locally in `assets/catalog-originals/`, excluded from the hosted bundle and Git. Earlier image versions are retained; `src/data/catalog-images.json` selects the 38 active variants and records visible provenance labels. `GarmentCatalogImage` falls back to the corresponding SVG if an image cannot load.

Validation: production build and 23 tests pass; all 38 WebP files decode. The browser loaded all 19 distinct catalog images, with no document overflow at widths 320, 360, 375, 390, 430, 768, 1024 and 1440px. Garment detail selects the larger image variant, and Studio still renders SVG with immediate color changes. The hosted website has not been republished.

AI images are conceptual educational illustrations, not authenticated artifact photography or definitive reconstructions. Existing cultural notes and source warnings remain visible. Community variants are labeled separately rather than presented as representative of every group or locality. Introductory comparisons were checked against [Vietnam Tourism](https://vietnam.travel/things-to-do/vietnam-traditional-dress-ethnic-groups) and the [Southern Women's Museum](https://baotangphunu.com/trang-phc-ci-truyn-thng-ca-ph-n-khmer-nam-b-2/); the generated weave and embroidery should not be treated as verified patterns.
